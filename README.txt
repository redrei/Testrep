IMPERIUM AETERNUM V — RPG IMPERIUM (v5.0)

Deploy every file in this folder to an HTTPS host such as GitHub Pages, Netlify, or Cloudflare Pages. Open the URL in Safari/Chrome and choose Add to Home Screen / Install App.

This release adds a Version 5 RPG overhaul on top of the dynamic imperial simulation, modern desktop graphics pass, interactive Mediterranean map, clickable provinces and cities, animated roads/routes/fronts, direct provincial orders, intelligence gathering, and code-rendered scene hotspots tied to real game actions. All game visuals remain generated in HTML, CSS, SVG, Canvas, WebGL, and JavaScript. No external artwork or runtime libraries are used.

Existing v2-v4 saves migrate automatically.


Version 4.2 adds a more realistic desktop GPU renderer with atmospheric shaders, richer procedural lighting, more expressive animated characters, and deeper motion effects.

Version 4.3 focuses on usability: graphical tab menus, icon-driven action buttons, a redesigned provincial atlas, and a visual province command panel.

Version 4.4 adds a stronger graphical UI, aligned screen layouts, a redesigned Senate chamber and war room, a persistent HUD, and a more geographically recognizable map of the Imperium.

Version 4.4.1 repairs submenu rendering and turns graphical hotspots, Senate seats and front nodes into object inspectors with related actions.

Version 4.4.2 repairs Capital, Senate, War Room, and Province Map navigation and click handling, including lexical save-state initialization and direct graphical control binding.

Version 4.4.3 fixes the private hero renderer scope error and restores scene-change notifications so Research and other visual feeds render correctly.

Version 4.5 adds a player Character screen with a code-rendered paper doll, equipment slots, unlockable traits, recovery orders, safer action cost handling, combat withdrawal, stronger save migration, and additional province governor orders to reduce soft-lock risk.

Version 4.5.1 restores access to the existing Military screen, adds a visible Journal tab, binds every graphical tab directly, and repairs governor-order attachment on the latest province map panel.

Version 4.6 refines UI and UX with a sticky command bar, clearer mobile navigation, consistent focus and hover states, visible action costs, blocked-action reasons, improved modal/toast styling, and denser responsive card layouts.

Version 4.7 vastly improves desktop graphics with a modern cinematic renderer, larger high-fidelity scene stage, dynamic scene palettes, bloom-style lighting, animated grid/skyline/traffic effects, upgraded glass panels, stronger map/chamber/war-room visuals, and safer layering so graphical controls stay clickable.

Version 4.8 vastly expands gameplay complexity with dynamic imperial crises, daily crisis escalation/fallout, rival schemes, an intrigue network, selectable empire-wide directives, personal ambitions, province construction projects, procedural Senate maneuvers, campaign polling and response operations, estate risk management, and research momentum that affects other systems.

Version 5.0 overhauls the RPG core with character archetypes, perk points, a perk tree, renown, reputation axes, quest contracts, explorable districts, usable inventory items, wounds, tactical combat choices, companion party roles, RPG rewards, and cross-system quest progression.

Version 5.0.1 is a balance pass only: it reduces runaway money, influence, intel, perk-point and project progression, closes a rival-handling exploit, slows daily snowball effects, and makes crisis, quest, exploration, companion and combat rewards more proportional to their costs and risks.
