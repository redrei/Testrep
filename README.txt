IMPERIUM AETERNUM — IPHONE INSTALLATION WITHOUT A MAC

This is a Progressive Web App. iOS requires it to be served from an HTTPS website; opening index.html directly from Files will not enable installation or offline mode.

PHONE-ONLY DEPLOYMENT USING GITHUB PAGES
1. On your iPhone, create or sign in to a GitHub account in Safari.
2. Create a new public repository, for example: imperium-aeternum.
3. Upload every item in this folder to the repository root: index.html, manifest.webmanifest, service-worker.js, and the icons folder.
4. Open the repository Settings, choose Pages, set Source to “Deploy from a branch,” select main and /(root), then save.
5. Open the Pages address GitHub provides. It usually resembles https://YOURNAME.github.io/imperium-aeternum/
6. In Safari, tap Share, then Add to Home Screen.
7. Launch Imperium from the new Home Screen icon. After its first successful load, it can run offline.

Saved games remain on that iPhone/browser installation. Clearing Safari website data removes them.
