IMPERIUM AETERNUM III — VERSION 3.0

A major grand-strategy update to the political RPG.

NEW IN V3
- Five foreign powers with persistent relations, tension, trade and intelligence
- A diplomacy screen with summits, trade agreements and espionage
- Two living military fronts and strategic operations
- Four multi-week imperial megaprojects
- Eight rival great houses with loyalty, power and autonomous schemes
- Four government doctrines that alter daily simulation
- A permanent imperial chronicle and legacy score
- Dynamic international moves, frontier pressure and political leaks
- Code-drawn strategic war map
- Full migration of Version 2.x saves through the existing imperiumV2 save slot
- Existing PWA, offline play, Canvas graphics and desktop WebGL graphics retained

INSTALL
Host all extracted files together over HTTPS, open the site in Safari/Chrome/Edge,
and choose Add to Home Screen / Install App.

No external scene art, textures, models, fonts, shader files or libraries are used.
